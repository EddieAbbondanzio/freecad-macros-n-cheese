# Freecad Macros-n-Cheese

A collection of my own macros.

## Layout

```
docs/     # Documentation. Mostly for the repo, not so much the macros.
macros/   # .FCMacro files
```

## Setup

1. In FreeCAD: **Edit → Preferences → General → Macro**.
2. Set **Macro path** to the absolute path of this repo's `macros/` dir, ex:
   `/home/cool-user-bro/freecad-macros-n-cheese/macros`.
3. Restart FreeCAD.

The macros should show up under **Macro → Macros…**. You can one to a toolbar via: **Tools → Customize → Macros**, and assign it under **Toolbars**.

Note:
- The above only works if you don't use any other macros.
